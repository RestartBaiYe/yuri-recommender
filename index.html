📖 使用说明

HOW TO USE · 花占卜指南

🌸 权重滑杆

页面顶部有五个滑杆，分别控制剧情与深度、角色塑造、作画/演出/音乐、百合浓度、热门程度的权重。把滑杆推向你最在意的方向，下方番剧列表会根据你的偏好实时重新排序。

🌐 实时数据

番剧库通过 GitHub Actions 定时从 AniList 同步：自动补充最新季度 Yuri 新番、更新封面与社区评分。页面头部会显示「数据更新于」时间戳。离线时使用内置的精编数据兜底。

🗳️ 社区评分与我的评分

热门程度维度是动态的：融合了 AniList 社区均分、社区人气与手工人气，因此其他用户（AniList 社区）的评价会实时影响每部番的排位。点击卡片进入详情后，你可以用「我的评分」滑杆给自己看过的番打分，评分保存在本机浏览器（localStorage），并会替代社区均分参与你自己的排名计算。

🔍 搜索与筛选

在搜索框中输入番名、标签、年份或制作公司即可快速筛选。点击下方标签芯片可以按类型过滤；「自动收录」标签代表由 AniList 自动发现的新番，评分为社区数据估算。

📊 排序方式

支持五种排序：占卜结果（按加权分数）、年份（最新优先）、名称（字母序）、百合浓度（浓度优先）、社区均分（AniList 均分优先）。

💡 小贴士：点击「重置权重」可恢复默认值；五维评分除「热门程度」外为主观评价，仅供参考；收录范围含真百合、轻百合与自动收录新番。

📝 评分说明

  • 五维评分均采用 10 分制；综合分 = 各维度 × 对应权重 的加权平均
  • 「热门程度」= 手工人气×0.45 + 社区均分×0.35 + 社区人气×0.20（有「我的评分」时社区均分由我的评分替代）
  • 社区均分来自 AniList 用户评价（0-10 分），实时同步
